
# Drug Target Extractor and PDB Identifier Finder

## Project Description
A Python-based bioinformatics application that identifies potential drug targets from research articles and searches the RCSB Protein Data Bank for corresponding experimental protein structures.

## Features
- Upload research articles in TXT format.
- Paste copied research article text.
- Identify potential protein and gene targets.
- Search RCSB PDB for candidate structures.
- Retrieve PDB identifiers.
- Display structure title, experimental method and resolution.
- Optional CSV result download.

## Technologies
- Python
- Tkinter
- RCSB Protein Data Bank API
- Regular Expressions

## How to Run

```bash
python main.py
```

## Database
https://www.rcsb.org/

## Note
PDB matches require scientific verification before use.
